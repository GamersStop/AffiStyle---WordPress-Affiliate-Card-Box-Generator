# High-Conversion Landing Page

Engineering framework for high-converting SaaS, WordPress plugin, and digital product landing pages. Provides structural module sequencing, outcome-driven copywriting rules, responsive design benchmarks, and execution validation.

---

## 1. Structural Architecture & Core Modules

Every high-converting landing page built under this skill must contain these structural modules in sequential order:

1. **Header / Sticky Navigation:** Brand logo, contextual anchor links, documentation/login link, and a high-contrast primary action button.
2. **Hero Section (Above the Fold):**
   - *Trust Pill / Eyebrow:* Micro-badge indicating compatibility, milestone, or version.
   - *Primary Headline (H1):* Direct business outcome in 6–10 words.
   - *Supporting Subhead:* 1–2 sentences explaining how the product delivers the outcome.
   - *Primary CTA Pair:* High-contrast conversion button alongside a low-friction exploratory secondary button.
   - *Friction Reducer:* Reassurance line (e.g., *14-day refund window • No credit card required*).
   - *Hero Visual / Demo:* Interactive preview, high-res UI snapshot, or card showcase.
3. **Social Proof Bar:** Immediate trust anchors (active install counts, platform logos, review averages).
4. **Problem-Agitate (Pain Discovery):** Direct contrast between current broken workflows and wasted time or lost revenue.
5. **Transformation & Solution:** Clear illustration of the "Before vs. After" state when adopting the product.
6. **Feature Value Stack:** Alternating 2-column benefit modules pairing a high-priority capability with a visual showcase.
7. **Feature & Capability Matrix:** Direct comparison table (Competitor vs. Your Product OR Free vs. Pro).
8. **Extended Social Proof & Testimonials:** Authentic customer feedback cards displaying user names, roles, and concrete outcomes.
9. **Value Stack / Pricing Tiers:** Transparent price cards highlighting key deliverables, updates, and guarantee badges.
10. **Success Condition / Guarantee:** Dedicated risk-reversal block with explicit terms.
11. **Secondary CTA (The Final Catch):** High-converting closing strip reiterating the core benefit and primary action.
12. **Footer:** Legal disclaimers (FTC, affiliate disclosures), licensing, documentation links, copyright, and brand parentage.

## 2. Section-by-Section Copywriting & Design Rules

### Hero Section & Visual
- **Headline Rule:** State the exact metric or workflow improved. Never use generic claims like "The Best Solution for You".
- **Visual Asset:** Represent the actual product interface or output, not abstract stock vector art.
- **Copy Reference:** See [copywriting-formulas.md](references/copywriting-formulas.md) for headline formulas and friction reducers.

### Problem-Agitate Framework
- Highlight 3 specific frustrations the user currently experiences.
- Quantify the impact (e.g., lost affiliate revenue, wasted design hours, bloated page speeds).
- Pivot immediately from agitation into how the product solves these frustrations cleanly.

### Transformation Showcase
- Present the explicit transition:
  - **Before:** Manual setups, clunky shortcodes, missing tracking, broken mobile cards.
  - **After:** Fast visual blocks, automated compliance disclaimers, real-time analytics.

### Value Stack & Pricing
- Ensure each tier explicitly lists:
  - Number of sites/domains licensed.
  - Feature inclusions and exclusive pro capabilities.
  - Support SLA and renewal discount details.
- Mark one tier visually as the "Most Popular" or "Best Value".

### Success Condition & Risk Reversal
- Include an explicit guarantee badge (e.g., *100% 14-Day Money-Back Guarantee*).
- State the terms clearly: zero hidden conditions, prompt refunds if the tool does not meet expectations.

### Secondary Call to Action
- Place directly above the footer.
- Keep copy urgent and conclusive: summarize the primary value proposition, show one clear primary button, and re-anchor the guarantee.

## 3. Visual & Responsive Benchmarks

| Component | Standard Benchmark |
| :--- | :--- |
| **Primary CTA Size** | Minimum 48px height, min 16px font-weight 600, high contrast against backdrop |
| **Typography Scale** | Desktop H1: 44px–56px; H2: 32px–40px; Body: 16px–18px (line height 1.5) |
| **Mobile Scaffolding** | Hero text and primary CTA must render within the initial viewport on mobile devices |
| **Spacing Rhythm** | 80px–120px vertical padding between desktop sections; 48px–64px on mobile |
| **Core Web Vitals** | Target LCP < 1.2s, CLS = 0, zero external render-blocking scripts |

## 4. Execution Checklist for Landing Page Generation

- [ ] Is the primary value proposition legible in under 5 seconds?
- [ ] Does the page have only ONE primary conversion objective throughout?
- [ ] Is every feature framed as a user outcome rather than raw technical jargon?
- [ ] Are trust signals placed both above the fold and directly near purchase buttons?
- [ ] Is the risk completely removed via a visible guarantee and transparent terms?
- [ ] Does the secondary CTA catch visitors who scrolled to the bottom without converting?
