AffiStyle Documentation

Version 1.0 • Developer Guide

Integration instructions for setting up AffiStyle on your WordPress website.

1. Installing the Free Version

  1. In your WordPress Admin, go to Plugins → Add New.
  2. Search for AffiStyle.
  3. Click Install Now and then Activate.

2. Adding Your First Card

Open any post or page in the Block Editor (Gutenberg), click the + button, search for AffiStyle Card, and add product images, titles, pros/cons, and target affiliate links in the sidebar panel.

3. Pro License Activation

If using AffiStyle Pro, navigate to AffiStyle → License Settings in your WordPress dashboard, enter your Lemon Squeezy license key, and save settings to enable premium comparison templates.
