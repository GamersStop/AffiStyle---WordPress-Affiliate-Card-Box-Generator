# AffiStyle - WordPress Affiliate Card & Box Generator

**AffiStyle** is a premium WordPress plugin designed for bloggers, reviewers, and affiliate marketers. It streamlines the creation and presentation of high-converting product boxes, comparison cards, and call-to-action modules within WordPress posts and pages.

---

## 🚀 Key Features

* **Custom Post Type (`aff_box`):** Easily manage all your affiliate product cards from a dedicated, clean dashboard menu.
* **Gutenberg Block Integration:** A native custom block featuring a dropdown selector to seamlessly insert any saved affiliate box into content.
* **Shortcode Support:** Includes dynamic shortcode generation (`[aff_box id="123"]`) for flexible layout placement.
* **Advanced Styling & Customization:** 
  * Manual configuration for product descriptions, destination links, custom button text, and badges.
  * Direct media library image uploader.
  * Custom background and button color pickers.
* **Freemium & Licensing System:** Built-in Lemon Squeezy license key activation framework that unlocks advanced conversion templates and pro features upon purchase.

---

## 🛒 How Customers Purchase & Use AffiStyle

1. **Purchase:** Customers buy the **AffiStyle Pro** license via our secure checkout links hosted on Lemon Squeezy.
2. **License Delivery:** Upon successful checkout, Lemon Squeezy automatically generates and emails a unique license key to the customer.
3. **Activation:** Customers upload the plugin ZIP file to their WordPress dashboard, navigate to the **Pro License** settings page, enter their license key, and instantly unlock advanced pro features and templates.
