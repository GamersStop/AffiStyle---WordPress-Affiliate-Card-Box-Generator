---

## 📌 About This Repository

This repository hosts the static landing page, documentation guides, and blog articles for **AffiStyle**, deployed directly to GitHub Pages / web hosting.

### Key Highlights of AffiStyle
- **High-Converting Affiliate Boxes**: Clean, responsive review boxes, comparison cards, and product highlights.
- **Zero Layout Shift (CLS)**: Engineered for fast Core Web Vitals and SEO performance.
- **Native Gutenberg Blocks**: Lightweight with no heavy dependencies or slow external scripts.
- **Automated FTC Compliance**: Built-in disclosure notices and transparent affiliate labeling.
- **Link Management & Cloaking**: Clean affiliate link handling with optimal rel attributes (`nofollow`, `sponsored`).
